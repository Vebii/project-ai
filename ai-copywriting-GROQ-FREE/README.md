## 🛠️ Quick Start

### 1. Install Dependencies

```bash
cd "C:\Users\Revitha Vebiola\Documents\website AI\ai-copywriting-project"
pip install -r requirements.txt
```

### 2. Dapatkan API Key Groq (GRATIS!)

1. Buka https://console.groq.com/
2. Sign up dengan Google (gratis, tidak perlu kartu kredit)
3. Klik "API Keys" → "Create API Key"
4. Copy API key yang muncul

### 3. Setup API Key

Copy file `.env.example` menjadi `.env`:
```bash
copy .env.example .env
```

Edit file `.env` dan paste API key Anda:
```
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxx
```

### 4. Jalankan Website

```bash
python app.py
```

Buka browser: **http://localhost:5000**

## 🔧 Troubleshooting

### Error: "API key belum diatur"
- Cek file `.env` sudah dibuat
- Pastikan isi: `GROQ_API_KEY=gsk_xxx...`

### Error: "API key tidak valid"
- Cek API key di https://console.groq.com/keys
- Buat API key baru jika perlu

### Error: "Rate limit tercapai"
- Groq gratis: 30 req/menit
- Tunggu 1 menit, coba lagi

### Website tidak bisa diakses
- Pastikan `python app.py` tidak error
- Cek port 5000 tidak dipakai aplikasi lain

**Lihat INSTALASI-GROQ.md untuk panduan lengkap!**
